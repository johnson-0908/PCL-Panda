# 界面精简与本地个性化

本地展示名称统一为「PCL2复活版」：默认左上角标题、窗口标题、产品属性和本修改版说明共用品牌定义。
启动页右上角不再显示重复品牌标签。自定义标题/图片功能、原作者署名和许可保留；账号、配置范围、程序集/EXE 文件名与公共仓库地址不迁移。

- 移除“更多”主导航、帮助/帮助详情、关于与鸣谢、百宝箱页面，以及反馈、投票入口。
- 对应页面源码、编译项、内置帮助压缩包和仅用于鸣谢页的头像资源均删除，不是运行时隐藏。
- 清理关联的功能隐藏设置、帮助加载器、自定义帮助/百宝箱事件、空的内存优化功能和启动提示。
- 原有其他页面与自定义事件的数字 ID 不变；旧的已移除页面 ID 不会误跳转到其他功能。
- 仅在“设置 → 其他”末尾保留简要的原作者署名、赞助链接、来源与许可证信息，原始 `LICENCE` 不变。

个性化提供 14 个本地预设配色及自定义色调、饱和度、渐变、亮度，直接可用。
移除了赞助遮罩、解锁状态和隐藏触发器。配色是本分支独立实现的静态配色，
不包含、也不冒充上游未公开的主题特效。继续使用已有设置存储机制，默认蓝色不变。
背景图片、背景音乐和透明度保持原样。

## 启动页：游戏空间

- 左侧账户栏收窄为 280 DIP，账户内容靠上；低窗口高度下可独立滚动，启动操作仍固定在底部。
- 右侧默认显示本地游戏空间：当前版本与状态、切换/管理版本、安装游戏、发现资源、导入整合包、启动设置、游戏目录。
- 信息来自已加载的版本和目录，不额外扫描游戏、不请求新闻、不读账号令牌；没有游戏时显示安装/选择引导，而不是空白。
- 扫描和启动期间禁用版本切换、管理与安装，版本异常有独立状态；入口继续遵守功能隐藏设置和原有启动/版本锁检查。
- 默认主页设置原来的“空白”改为“游戏空间”。本地/在线自定义主页加载成功后仍独占右侧；空文件、加载中或解析失败时回退到游戏空间。
- 旧“你知道吗/回声洞”预设 ID 保留并回退内置主页，避免显示已删除模块的占位符。

界面功能不修改现有账号、游戏、存档；发布包不包含开发者的运行目录。
本地修改不意味着取得额外的上游分发授权；原始许可及指南仍保留。

## 检查

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File scripts/Test-Interface.ps1
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File scripts/Test-LaunchDashboard.ps1
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File scripts/Test-Branding.ps1
```

独立输出目录需追加 `-BinaryDirectory <输出目录>`。
该检查验证源码及编译产物中不含移除模块、路由数字保持稳定，并直接调用编译后的主题渲染器。
测试只建立无窗口的 WPF 资源宿主，用内存设置检查颜色更新，不启动启动器、不写账号和配置。
真实窗口操作与重启后的设置恢复仍需手动验收。
启动页检查使用编译后的只读状态模型和原生 XAML 子树，以合成数据测试空、已选、异常、加载、启动、超长文本状态及三种宽度；
可追加 `-PreviewDirectory <输出目录>` 保存离屏 WPF 渲染。不打开或控制实际窗口，不执行按钮动作，不访问真实游戏数据。
